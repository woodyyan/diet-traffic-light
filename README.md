# 饮食红绿灯（尿酸 · 血脂 · 血糖）

输入食物名，立刻告诉你能不能吃、吃多少、为什么。面向**高尿酸 / 高胆固醇 / 高甘油三酯 / 需要控糖**人群的日常饮食自查工具。

纯静态单文件应用，零依赖、零后端、可离线，数据只存在本机。

https://diet-traffic-light.app-tencent.workbuddy.host/

手机浏览器打开后「添加到主屏幕」，即可像 App 一样使用。

## 菜名扩充版（2026-10-14）

当前 938 条独立预置食物、1282 个唯一别名。本轮新增 375 条，并合并两个重复条目，区分原料、卤制、红油凉拌、加工肉、香草蔬菜与素菜成品。

完整主名优先于精确别名，再进行模糊匹配；口条归猪舌、卤猪耳归卤猪耳朵、牛筋与牛腱分开、香菜独立收录。全库主名和别名均无多重归属，允许少量总类/具体项名称重叠，完整主名优先。

新增条目标注 `estimated:true`，份量及风险档为常见原料/做法的参考，不是逐菜检测。无可靠 GI 数据时不生成 GI 数字，淀粉食物用 `starchy:true` 提醒控糖；低糖不等于无碳水。脂肪提醒要结合油种及用量，不能把植物油一概视为高饱和脂肪。

页面底部显示版本和真实收录数量；构建时根据页面内容摘要自动更新 Service Worker 缓存键。

## 使用

首次打开在右上角 ≡ 里填入自己的体检四项（UA / LDL / TG / 空腹血糖），判定结果会按你的实测值显示；不填也能用，默认按通用上限（UA 420、LDL 3.4、TG 1.7、空腹血糖 6.1）判断。数值与查询记录都只存在本机 localStorage，不上传、不同步、仓库里不含任何个人数据。

## 判定逻辑

每种食物按五个维度分级：`lv = [嘌呤, 胆固醇, 饱和脂肪, 糖, 钠]`，取值 `0=低 / 1=中 / 2=高`，阈值参考《中国食物成分表》及高尿酸血症、血脂异常相关膳食共识的通用分类（嘌呤低 <50、中 50–150、高 >150 mg/100g）。

再归到四个轴，取最严的一档决定灯色：

| 轴 | 看什么 | 红灯情形 |
|---|---|---|
| 血尿酸 UA | 嘌呤、果糖、酒精 | 高嘌呤、任何酒、浓肉汤 |
| 坏胆固醇 LDL | 饱和脂肪（权重高）、膳食胆固醇（权重低一档） | 饱和脂肪高、内脏、油炸 |
| 甘油三酯 TG | 糖、精制碳水、酒精、GI | 含糖饮料、果汁、甜点、油炸 + 精制碳水 |
| 血糖 GLU | 添加糖 + 升糖指数 GI | 含糖饮料、甜点、GI ≥ 85 的精制主食（白粥、白馒头、年糕） |

血糖轴规则：GI ≥ 85 → 红灯，GI ≥ 70 → 黄灯；添加糖分两档（糖 2 直接红灯、糖 1 且 GI < 56 视为不冲血糖而降级）；`sweet` 标签（含糖饮料、果汁）直接红灯；酒类至少黄灯。
库里没标 GI 但明显是精制主食的（阳春面、凉面、饭团…）默认按 GI 75 处理；杂粮饭（65）、荞麦面（54）、意面（49）仍是绿灯——这一轴的意义就在于把它们和白米白面区分开。

设置里可以关掉「血糖轴计入总判定」：四条轴照常显示，只是不参与总红绿灯。

特殊标签：`alcohol`（酒）、`soup_meat`（肉汤骨汤，嘌呤和油脂都溶进汤里）、`fried`、`processed`、`organ`。

### 查不到时的四层兜底

1. **做法 + 食材自动拆解**：拆出做法词（炒 / 粉蒸 / 水煮 / 炖煲…共 20 类，各带油量、是否加糖、是否带汤三个属性）和主料，分别判定后组装。"粉蒸排骨"不会再串出"别喝汤"——只有带汤的做法才会提汤。
2. **包装零食品牌 → 品类**：约 90 个常见品牌映射到 13 个零食品类（脆脆鲨 → 威化夹心 → 红灯）。
3. **类别规则**：22 条通用规则（油炸、内脏、贝类、酒精、含糖饮料…）。
4. **包装食品看营养成分表**：翻到背面填每 100 g 的饱和脂肪、糖、钠三个数，勾上「是主食/淀粉类」再补一档血糖轴，直接算灯色和一次能吃多少。品牌永远补不完，营养成分表才不会骗人。

判据：饱和脂肪 > 5 g、糖 > 15 g、钠 > 800 mg，任一项即红灯；过半即黄灯。

## 目录结构

```
src/foods-1.js   主食、肉蛋
src/foods-2.js   水产、豆制品、蔬菜、水果
src/foods-3.js   奶制品、坚果、饮料、零食、调味油脂
src/foods-4.js   具体菜名、汤品、粉面、早餐烘焙、卤味甜品
src/foods-5.js   常见家常菜与地方菜（第二批）
src/foods-6.js   常见饮料专辑
src/foods-7.js   肉类部位、卤味、内脏、禽畜与加工肉
src/foods-8.js   香草蔬菜、鲜菌菇、素菜凉菜和豆制品
src/packs.js     包装零食品牌 → 品类规则 + 营养成分表判定函数
src/dishes.js    复合菜式（拆到配料分别判定）+ 做法规则 + 22 条类别兜底规则
src/app.js       判定引擎与界面渲染
src/template.html 页面骨架与样式
build.js         把上面全部内联成单文件 dist/index.html
gen_icon.py      生成 PWA 图标
test.js          判定自检（关键食物是否符合预期灯色）
smoke.js         渲染冒烟测试
dist/            构建产物，可直接静态托管
```

## 本地开发

```bash
node build.js    # 生成 dist/index.html，并自动更新离线缓存键
node test.js     # 判定自检
node smoke.js    # 渲染冒烟
```

改食物库：编辑 `src/foods-*.js` 或 `src/dishes.js`，然后重新 `node build.js`。
`dist/index.html` 是自包含的单文件，双击也能直接用。

## 部署

项目根目录已带 `vercel.json`（`buildCommand: node build.js`，`outputDirectory: dist`）。
在 Vercel 导入仓库后无需额外配置；任何静态托管（GitHub Pages、Netlify、对象存储）直接托管 `dist/` 也可。
